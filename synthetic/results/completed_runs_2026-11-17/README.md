# Completed-run analysis bundle

This bundle collates the completed synthetic notebooks 00–06 and `faster-machine-03` result artifacts as of 17 November 2026. It is an analysis archive with derived summaries, figures and provenance. The main driver benchmark fails for all four methods; the long-history mechanism result is a favorable development diagnostic on existing seed 20. Repeating existing seeds adds no independent confirmation to the November 15 evidence. The separate graph-comparison development study and notebook 07 are outside this archive.

Start with [analysis-report.md](analysis-report.md), then consult [numeric-summary.md](numeric-summary.md), [stats-appendix.md](stats-appendix.md) and [figure-catalog.md](figure-catalog.md). The [tables](tables/) retain numerical values and the [figures](figures/) contain framework, driver and mechanism comparisons. Completion counts are 24 native sanity runs, four shared-comparison lanes, 48 framework runs, 560 driver runs and 36 mechanism lanes, including 12 known/empty-support controls. Counts across stages are not a pooled scientific sample size.

The [audit JSON files](audits/) contain the structured evidence and comparison units used by [reproduce_analysis.py](reproduce_analysis.py). [inputs.zip](inputs.zip) archives the selected completed input artifacts; [executed-notebooks.zip](executed-notebooks.zip) preserves the executed notebooks and their saved outputs. [implementation-source.zip](implementation-source.zip) contains the current implementation, protocols, runtime locks and methodology documentation. File identities and collection details are recorded in [provenance.json](provenance.json); [environment.json](environment.json) records the analysis environment. The verified statistical references and their limits are in [analysis-references.bib](analysis-references.bib) and [citation-audit.md](citation-audit.md).

From the inner repository root, using the existing project environment, regenerate the derived figures and tables with:

```sh
.venv/bin/python synthetic/results/completed_runs_2026-11-17/reproduce_analysis.py
```

The script reads the shipped audit files and writes derived analysis artifacts. It performs no estimator fits, simulator reruns or notebook execution, and does not require extracting the ZIPs or access to historical Git objects. The archives are assembled from the completed evidence independently of this script; regenerating the tables and figures does not rebuild them. Full framework cell snapshots and the older driver's large native/feature arrays remain in local `outputs/` rather than the archive; their paths and sizes are listed in provenance. Completed reports, metric records and acceptance decisions are preserved, along with the mechanism's compact native evidence. Reproducing the original fits requires the corresponding source, configurations, upstream runtimes and full run evidence. Use the [project reproduction/install instructions](../../../README.md) and [synthetic workflow guide](../../README.md) for that separate task.

Historical comparison uses the frozen November 15 artifacts from commit `8ce5ec6`, read through Git without restoring deleted working-tree archives. The audits retain the compared numerical evidence; this bundle is not a complete copy of every historical software environment. Conventional CPU permutation randomness is not fully controlled, so identical configuration and raw seed do not guarantee identical conventional discovery outputs. Native edges are unsigned lagged support decisions and do not supply intervention distributions or biological necessity. The [methodology revision](../../../docs/driver_methodology_revision.md) explains the distinction between graph-feature omission and structural disconnection, and the [four-method migration record](../../../docs/four_csl_migration.md) documents the native estimator boundary.

Framework smoke has only three seeds per specification and all 16 adjusted p-values equal 1. Mechanism comparisons have one existing process seed and uncalibrated nomination; zero false events in one null seed still gives a 0.95 upper bound. Fresh independent seeds, a frozen revised protocol and adequate separate null calibration are required before stronger recovery or specificity claims. Saved notebook outputs remain source evidence; this collation does not revise them.
