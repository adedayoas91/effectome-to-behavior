# Diagnostic figure catalog

`01-endpoint-semantic-error`: true simulator effects through each endpoint versus independently defined behavior, by scenario. `02-behavioral-effect-error`: fitted mechanism effects through each endpoint versus true behavioral effects.

Bars average 1 process seeds, and each dot is one process seed. Methods, trials, candidates and endpoint arms are paired conditions, not extra replicates. No confidence intervals or confirmatory significance are asserted. Values come from the frozen report and `seed-metrics.csv`; all methods and endpoints retain their declared identity.
