# Learned behavioral endpoint: initial development bridge

Five development seeds (40000--40004), driver and endpoint-null scenarios, seven neural-dynamics lanes and seven endpoint arms. This is a linear PCA bridge, not nonlinear-manifold confirmation.

Start with `analysis/analysis-report.md`, `analysis/seed-metrics.csv` and the copied method plan. `run-evidence.zip` contains first-completed native support, endpoint artifacts and binary rollout events. `implementation-source.zip` preserves the executed implementation. No native estimator was rerun to export.

See `development-findings.md` for measured results, implications and source-version limits. The first run exposes a PCA semantic failure rather than a successful compressed behavioral manifold. Its archived status flag inherited fitting_enabled=False from inventory despite the complete fitted evidence; subsequent code corrects that metadata and strengthens origin/resume checks.
