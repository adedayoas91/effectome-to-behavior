# Statistical scope

The independent unit is a simulation seed. Conditions share innovations within seed; all methods receive the identical recording. Neurons, directed edges and method variants are not independent replicates. Means and sample SD describe seed-level metrics.

This bounded pilot is descriptive. No significance test, ranked winner or population recovery guarantee is justified. No multiple-comparison claims are made. Null intervals below are two-sided exact 95% binomial intervals for ANY false edge in a null graph, separately per method, without simultaneous coverage across methods.

- c-GC: null graphs with any false edge 0/3; exact 95% interval [0.000, 0.708].
- c-GC*: null graphs with any false edge 0/3; exact 95% interval [0.000, 0.708].
- fastC-GC: null graphs with any false edge 0/3; exact 95% interval [0.000, 0.708].
- fastC-GC*: null graphs with any false edge 0/3; exact 95% interval [0.000, 0.708].
