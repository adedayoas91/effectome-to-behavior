# Behavioral rollout checkpoint, 19 November 2026

The [compiled manuscript](manuscript.pdf) records Trials 7–10 in
Methodological Development and Decisions. The [LaTeX source and PDF
bundle](manuscript-source-and-pdf.zip) can be rebuilt with `tectonic main.tex`.

- [Continuous readout confirmation](behavior-readout/analysis-report.md) passed
  the frozen decision on 99 cases. It motivated the behavior-only readout.
- [Recurrent-coupling development](recurrent-development/analysis-report.md)
  identified mechanism rollout as the stronger forecast candidate.
- [Isolated rollout confirmation](isolated-rollout/analysis-report.md) missed
  its forecast criterion for support rediscovery. The descriptive comparison
  favored local refitting on fixed support.
- [Post-switch timing confirmation](post-switch-timing/analysis-report.md)
  found first supported delays of 19.2 and 76.8 seconds for 256- and 1,024-sample
  histories. The [timing figure](post-switch-timing/post-switch-forecast-gain.pdf)
  shows the driver and control trajectories.

The reports and seed tables were copied from the completed runs. Each run
protocol retains the code and runtime fingerprint used at execution. Raw
per-origin forecasts, native fit evidence, and checkpoints live in the local
run directories named in the linked study plans.
